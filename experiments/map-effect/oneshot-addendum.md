
## One-shot arm: no device

This trial measures generating a test without running it. There is no device for you: no `./maestro`,
no `./reset.sh`, no `adb`. Ignore the instructions above about running Maestro or resetting the app.
Write `flow.yaml` from this brief and `map.md` (the app map) alone, run `./check.sh flow.yaml` and fix
every error it reports, then stop. Do not guess beyond what the map and brief say.
